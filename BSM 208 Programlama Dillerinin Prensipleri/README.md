## 🧭 Overview

This repository contains two different implementations of the same space simulation assignment, written in **Java** and **C**. Both simulate interplanetary travel between planets with distinct day lengths and handle spacecraft movement, traveler aging, and vehicle states.

The main goal of this project is to explore **object-oriented design principles** across different languages:

- 🔹 **Java Version**: Emphasizes full OOP practices with class hierarchies, encapsulation, and real-time console interaction.
- 🔹 **C Version**: Mimics OOP design using structures, function pointers, modular architecture, and memory management.

## ✨ Shared Assignment Goals

* Read planet, spacecraft, and traveler data from `.txt` files
* Simulate each planet's time independently (variable hours per day)
* Activate spacecraft on their designated departure date
* Decrease passengers' remaining lifespan every hour
* Destroy spacecraft if all passengers die before reaching destination
* Arrive spacecraft and update destination planet's population
* Generate a detailed end-of-simulation report
