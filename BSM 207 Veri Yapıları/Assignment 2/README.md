# Assignment 2: Binary Search Tree and Linked List Implementation

## 📌 Course
BSM 207 - Veri Yapıları (*Data Structures*)

## 📄 Description
This assignment focuses on organizing text-based data into **binary search trees (BSTs)** and linking these trees using a dynamic linked list. It includes an interactive console for navigating and modifying the trees.

## ✨ Features
- Creates a BST from each line of a file.
- Links BSTs into a navigable list.
- Supports mirroring and deletion of trees via keyboard input.
- Displays trees and lists with visual alignment enhancements.
- Calculates each tree's total ASCII value using a custom formula.

## 💡 Learned Concepts
- Linked lists and tree traversal.
- Visualization and interface handling.
- Dynamic memory management.

## ⌨️ Controls
- `a` / `d`: Navigate left/right in tree list.
- `w`: Mirror current tree.
- `s`: Delete current tree.

## 🛠️ Compile & Run
```bash
mingw32-make
./Assignment2.exe 
```

## ⚠️ Known Limitations
Basic console UI, limited user-friendliness.

Visualization could be improved for large trees.
